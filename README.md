# SkribeMonkey
AI-assistant for emergency health care workers. Records patient interactions and creates patient records automatically. Built during Knight Hacks 2024.

# Key Features
Audio-upload and transcription: Health care worker records patient interactions and uploads the audio to be transcribed [Native Audio Recorder -> File Upload -> OpenAI Whisper]

Patient Data Formatting and Triage: Transcribed patient interactions get formatted into concise patient records [Transcription -> LLM -> Supabase]

# Stack
Built using Flutter and Supabase.
