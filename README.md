# SkribeMonkey
AI-assistant for emergency health care workers. Records patient interactions and creates patient records automatically. Built during Knight Hacks 2024.

# Key Features
Audio-upload and transcription [Native Audio Recorder -> File Upload -> OpenAI Whisper]

Patient Data Formatting and Triage [Transcription -> LLM -> Patient Record Creation]

# Stack
Built using Flutter and Supabase.
